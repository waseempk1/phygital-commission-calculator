Phygital Commission Calculator - June 2026

Files:
- index.html: complete static web calculator. Upload this file to any static hosting platform.

Hosting:
- GitHub Pages: create a public repository, upload index.html, enable Pages from repository settings.
- Netlify: drag and drop the folder or zip on Netlify's deploy page.
- Firebase Hosting: use Firebase CLI and deploy the folder as a static site.
- Cloudflare Pages: connect a Git repository or upload the static files.

Tax factor:
- Default net payout factor is 86% of gross commission.
- Change the value in the webpage input if needed.
